The Study Table — redesign brief
Assumptions: front-end only — engine API, keymap and two-phase placement stay as-is · desktop ≥ 1280 · classic four colors, custom palettes preserved · light + dark themes from one variable set (1b / 1c).
WHAT'S WRONG TODAY
1 · No focal point. The board is 480px in the top-left; four equal-weight trays outshout it.
2 · Your hand isn't privileged. All 84 pieces render identically at 12px; selecting feels like data entry.
3 · Turn state is prose. "turn 13 · player 0 · active blue" + a 12px pill — not glanceable.
4 · Actions are detached. Native buttons under the board; the keymap hides in a popover; scroll-to-rotate and right-click-flip are undiscoverable.
5 · Thin feedback. Illegal = red tint, no reason. No placement moment. Game over is a bare table.
6 · Chrome scattered. Theme / palette / help pinned bottom-left like debug switches.
7 · One premium thing, buried. The skeuomorphic piece finish is great — the rest of the page doesn't live up to it. Keep it, amplify it.
THE CONCEPT
The match is a physical table. The board is an object — a walnut-framed, recessed well at dead center, the only thing with real depth. Everything else is paper on the table: ivory cards with contact shadows. Left, who's playing (turn order runs top→down). Right, your hand, grouped by piece size. Below the board, one action dock that reads in the order you think: what's in hand → orient → confirm. Skeuomorphic where it earns tactility (pieces, wells, keycaps); flat where clarity wins (text, labels). Type: Instrument Sans / Serif + IBM Plex Mono for counts and keycaps.

INTERACTION DECISIONS
Hybrid placement (your pick). Hover ghost → click stages → Confirm pulses. Two-phase stays: placement is irreversible in Blokus, so the confirm beat is protection, not friction.
Keymap kept verbatim (A/D rotate, F flip, arrows nudge, Space stage, Enter, Esc) — but surfaced as keycaps on the controls instead of a help table. Scroll-rotate & right-click-flip stay, advertised in the status line.
Illegal moves explain themselves. Red ghost + a toast naming the broken rule: "needs corner contact", "shares an edge with Blue", "overlaps", "off board".
Your tray is the only tray. Opponents compress to counts + a 21-dot inventory — the info that matters (what's left, who's ahead) without 63 tiny shapes.
Board auto-rotates so your corner is bottom-right (kept from the repo), animated as a framed object turning.
